## 发现的数值限制

本次新生成的一组 N8192/Q38 上下文，MVM 后 Bootstrap 最大绝对误差约 8.99e-4，超过原 5e-4 阈值。使用同一输入和密钥，输出 Q6 与 Q8 均出现该误差；单次 rotate＋multcp＋Bootstrap 也在这组材料上出现约 6.89e-4 的误差。该检查没有标为通过。

已确认共享的 14 个底层计算模块的机器指令与上一版一致，参数、自举 FFT 明文和标量材料一致。既有 N8192 材料的重放通过，但新材料精度异常的根因尚未定位。因此不能将已有材料上的验收结果理解为所有新材料都满足同一误差阈值。

额外尝试把稀疏边界输入送完整两层片段时，部分第二层输出超过 1e-3；卷积边界的正式检查限定在第一层卷积，并独立验证全部槽位。原有两个真实样本的完整两层片段均通过。

维护者的原始报告在 `soft/clib/build/sdk/acceptance/`、`asan-tests/` 和 `diagnostics/`，不随发布包附带密钥或测试工作目录。测试入口会保留失败结果并返回非零状态，不通过重试挑选材料或放宽容差隐藏失败。
